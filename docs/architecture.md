# 技术设计

## 分层与依赖

| 工作区 | 责任 | 工作区依赖方向 |
| --- | --- | --- |
| `packages/core` | 注册与解析预设、参数归一化、时间轴、挂载及销毁、可见性与降级协调 | 无 |
| `packages/effects` | ID、默认值、可序列化参数 Schema、渲染能力声明和动效实现 | core 的公开契约 |
| `packages/renderer-css` | 受控 DOM、CSS 样式及原生动画 | core 的渲染器契约 |
| `packages/renderer-canvas` | Canvas 2D 表面、绘制与高分屏控制 | 同上 |
| `packages/renderer-webgl` | WebGL 2 上下文、着色器、GPU 对象与上下文丢失处理 | 同上 |
| `packages/react`、`packages/vue`、`packages/web-components` | 统一属性和事件，适配宿主生命周期 | core，选用渲染器由接入方注入 |
| `apps/docs` | 展示根目录规范和发布版本对应的用法 | 已发布 API 或本地 workspace 包 |
| `apps/playground` | 注册表、参数编辑、预览、代码生成 | core、effects、所支持的渲染器 |

core 不反向依赖动效和渲染器。Vanilla JS 直接消费 core。包实现后再按实际引用加 `workspace:*`，框架依赖通过适配包的 peer dependency 声明。已实现的包通过私有工作区消费。发布前按包定义 ESM `exports` 和类型声明，动效按独立入口导入，CSS 入口保留样式副作用。用最小消费项目验证单个预设可被独立打包。

## 参数协议

| 参数 | 类型与默认 | 行为 |
| --- | --- | --- |
| `size` | 正数，24 | CSS px，用于紧凑动效。画布和骨架类以容器尺寸为准 |
| `color`、`background` | CSS 颜色，`#4D8DFF`、`transparent` | 可由预设覆盖。渲染器挂载时解析颜色 |
| `duration` | 正数，1200 | 单周期毫秒数。动效可声明自己的默认和边界 |
| `speed` | 0.2–3，1 | 时间增量倍率，实际周期为 duration / speed |
| `loop`、`paused` | 布尔，true、false | 单次播放到终帧后停止。暂停冻结当前相位，独立于进度更新 |
| `progress`、`progressSource` | 0–100 或 null，默认 null。来源为 `actual` 或 `estimated`，默认 actual | 进度由宿主更新，非有限值回到 null。实际百分比和估算必须明确区分 |
| `density`、`amplitude` | 可选数字 | 仅在支持的预设生效，由该预设声明单位和范围 |
| `opacity` | 0–1，1 | 统一乘在视觉层，语义层独立 |
| `renderer` | `auto`、`css`、`canvas`、`webgl`，默认 auto | 按能力声明选择并报告实际结果 |
| `reducedMotion` | `system` 或 `static`，默认 system | system 跟随系统偏好，static 始终使用静态姿态 |
| `label` | 非空文本，默认“正在加载” | 宿主可提供本地化状态名 |

参数合并顺序是公共默认、预设默认、调用方覆盖。按 Schema 校验枚举、有限数、整数、数组长度和容器相关上限。数值越界按字段范围截断，类型不符回退默认并返回诊断。默认值与已归一化的参数对象不得被调用方更新原始对象所污染。目录中各项专属默认是实现输入，未定义的专属参数上下限在该预设落地时确定，并以 Schema 和测试为准。

## 实例、时间轴与渲染契约

当前提供 `createLoading(element, options, registry)`，实例具有 `update(patch)`、`pause()`、`resume()`、`destroy()`。更新尺寸、颜色、进度和速度尽量复用实例。动效 ID 或实际渲染器变化才重建视觉层。销毁可重复调用，终态实例忽略后续更新。销毁释放帧回调、观察器、媒体查询监听、DOM 和 GPU 对象。新渲染器初始化失败时清理其临时资源，再走降级链。

定义层提供元数据、Schema、支持的后端、静态姿态和后端实现入口。渲染器提供 `mount`、`resize`、`update`、`pause`、`resume`、`destroy`，主动绘制后端增加 `render(frame)`。Canvas 和 WebGL 共用调度器，帧输入含累计时间、当前相位、增量、尺寸和参数。手动暂停、不可见、零尺寸和减少动态分别作为运行条件，全部恢复后才继续。恢复第一帧重置时间戳，避免补算后台时间。需要积分的效果限制单帧模拟步长和追赶次数，波纹等解析式直接按时间采样。

交互涟漪由宿主把触点转换为归一化坐标并调用 `trigger([x, y])`。Canvas 按实例保存波源，以累计动画时间推进脉冲。渲染器在波源全部过期后报告空闲，调度器停止请求下一帧。暂停和减少动态时忽略新触发，减少动态时绘制静态底图。

| 后端 | 实现与降级 |
| --- | --- |
| CSS | 小型几何、文本、进度、骨架。优先用 transform 和 opacity，样式限于实例容器。可用原生动画控制时钟，连续调速需保留当前播放位置。 |
| Canvas 2D | 点阵和中等规模粒子。缓存布局与相位，分辨率随容器和 DPR 调整，限制总缓冲像素。无法取得上下文时走声明的 CSS 预设或静态姿态。 |
| WebGL 2 | 大规模粒子、复杂材质和 3D。批量绘制并复用缓冲区。上下文丢失后停止 GPU 绘制并显示备用姿态，恢复后重建资源，再按现有相位继续。 |

auto 按预设的后端优先级、浏览器能力和资源预算选取。显式选择不可用时返回诊断并尝试预设声明的替代方案。最终降级为静态图形与可访问状态，进度语义层独立保留。

## 框架接入与 Playground

React 在 effect 中挂载，清理函数销毁，适配 Strict Mode 的重复挂载。Vue 在 mounted 后挂载，watch 更新参数，在卸载前销毁。自定义元素提供显式注册函数，复杂参数走 JS property，标量支持属性转换，断开时释放资源，再连接时按最新属性重建。模块导入阶段不读取 `window` 或注册元素。SSR 输出稳定尺寸的容器和文本，客户端挂载后替换视觉层。 Web Components 通过 `defineLoadingEffect()` 显式注册 `<loading-effect>`，可用 `registry` 和 `options` 设置注册表与复杂参数。标量 HTML 属性优先于 `options`，移除属性后恢复使用 `options` 中的值。

Playground 将预设按类别纵向排列，根据 Schema 生成每张卡片的控件。参数、演示进度和暂停状态按卡片保存，调参复用当前实例。引擎观察画布宿主的可见性，首次进入视口后分配画布缓冲区并绘制。离开视口时取消帧回调，重新进入时以已有累计时间绘制首帧。预设以带版本和动效 ID 的 JSON 表达，解析链接参数时只读已声明字段，拒绝过长或无效载荷。代码生成按适配器模板序列化参数，文本作为数据转义。每种发布的输出模板需要一个实际可运行的例子。

## 性能与无障碍验收

- 以 60 FPS 为前台目标。选定桌面与中档移动设备，记录系统、浏览器、视口、DPR、动效、实例数。对 800 × 450 点阵运行 30 秒，记录帧间隔 P50/P95、脚本绘制耗时和掉帧。以 P95 帧间隔 ≤ 20 ms、绘制脚本 P95 ≤ 6 ms 作为首版桌面验收预算。移动端记录原始数据和降级后的结果。
- Canvas 默认 DPR 上限 2，单实例缓冲区上限约 4 百万像素，点阵上限见详细规范。连续两个一秒采样窗超预算时先降低 DPR，再减少密度，当前实例内避免反复升降。粒子网络用空间分桶并限制每点连线数。
- 隐藏标签页或移出视口后停帧。重复挂载、改尺寸、暂停、销毁 50 次，检查回调、监听器和绘图资源可回收。验证 Canvas 初始化失败和 WebGL 上下文丢失的降级。
- 装饰层使用 `aria-hidden=true`。未知进度以可访问名称和 `role=status` 传达。确定和估算使用命名的 `progressbar`，设置 `aria-valuemin=0`、`aria-valuemax=100`、`aria-valuenow`，估算附带说明。动态装饰不得产生连续播报。
- 宿主可对内容区域设置 `aria-busy`，状态播报节点放在该区域外。播报限于任务开始、阶段变化和终态。进度文案的普通字号对比度目标为至少 4.5:1。Playground 控件可用键盘操作，焦点清晰。
- 系统减少动态时展示静态姿态，保留可读状态和真实进度，禁用淡出过渡。验收包括系统偏好在运行中改变、文本放大、键盘操作和读屏实测。
